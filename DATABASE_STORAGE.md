# Настройка постоянного хранилища для базы данных

## Проблема

По умолчанию база данных SQLite хранится в `/tmp/bookflix.db` на Vercel, что является временным хранилищем. Данные очищаются между вызовами serverless функций, что приводит к потере истории чатов и сообщений.

## Решение

Для обеспечения постоянного хранения данных необходимо настроить внешнее хранилище через переменную окружения `DB_PATH`.

### Вариант 1: Vercel Blob Storage (рекомендуется)

1. Установите Vercel Blob Storage в вашем проекте
2. Настройте переменную окружения `DB_PATH` для указания пути к blob storage
3. Адаптируйте код для работы с blob storage (требует изменения архитектуры)

### Вариант 2: Внешний SQLite через файловый сервис

1. Используйте внешний файловый сервис (например, AWS S3, Google Cloud Storage)
2. Настройте синхронизацию SQLite файла с внешним хранилищем
3. Установите `DB_PATH` на локальный путь, который синхронизируется с внешним хранилищем

### Вариант 3: Миграция на управляемую базу данных (лучшее решение)

1. Используйте Vercel Postgres или другую управляемую базу данных
2. Измените код для работы с новой БД (требует изменения архитектуры)
3. Это обеспечит надежное постоянное хранилище

## Временное решение

Для тестирования можно использовать переменную окружения `DB_PATH`, указывающую на постоянное хранилище, но это требует дополнительной настройки инфраструктуры.

## Текущая конфигурация

По умолчанию используется `/tmp/bookflix.db`, что приводит к потере данных между вызовами функций.

Для диагностики проверьте логи Vercel - там будет предупреждение, если используется временное хранилище.
